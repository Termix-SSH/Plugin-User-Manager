## Overview

Users manages the accounts on your hosts over SSH. Each host gets its own tab for users, groups, SSH keys and who is logged in.

Read the [docs](https://docs.termix.site/plugins/user-manager) to set it up and use it.

<br />

## Features

- See every account on a host with its groups, shell and password state
- Create users with a home folder, shell, groups, sudo and a password
- Set passwords, lock accounts and make users pick a new password
- Add and remove the SSH keys a user can log in with
- Create groups and change who is in them
- See who is logged in and recent logins
- A Users card in Host Metrics
- Lock, unlock and delete users through Termix actions, with empty passwords as a status tile

## Support

Problems with Termix itself (login, hosts, credentials, sharing, sync) go in the [Termix repo](https://github.com/Termix-SSH/Termix/issues/new/choose). Not sure where it goes? Open it there and it will be moved.
